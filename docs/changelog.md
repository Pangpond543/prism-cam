- 2026-11-23 — **Phone as a camera (no app to install)** — user: wanted a phone as a camera, fine controls (zoom, front / back), phone web page in the classic look only so it never stutters, "every system, no bugs".
  How: dock button "มือถือเป็นกล้อง" → QR code. Prism Cam serves a small HTTPS page on the home network (`phone.rs`, port 8543–8552, self-signed certificate made once and kept in the app data folder, pairing code in the link). The phone sends its camera straight to the studio page over WebRTC (H.264 preferred: the phone's video chip); the hand-shake and controls go through the page server (long poll) and a data channel. A phone layer is a normal camera layer with `phone: <id>` → hands, face, AI background, effects, animation all work on it.
  Phone page (`app/src-tauri/phone/`, classic flat dark look, no blur / animation): start screen, switch front / back, torch, pause (camera off), screen off (battery), pinch to zoom, tap to focus, zoom bar with 0.5× / 1× / 2×, settings sheet (lens, 720p–4K, 30 / 60 fps, quality, smooth vs sharp, focus / exposure / ISO / shutter / white balance / brightness / contrast / saturation / sharpness — whatever that phone's browser supports), status (sent size / fps / encoder / why reduced / battery), phone name, disconnect. Keeps the screen awake (Wake Lock), reconnects by itself (Wi-Fi drop, Prism Cam restarted, page reloaded), TH / EN follows the PC.
  Prism Cam side (`phonecam.js`): QR dialog (address picker, copy link, live list of phones, firewall check + one-click fix, change the pairing code), phone panel in the properties tab with every control above + live numbers (size, fps, Mbit/s, ping, battery), placeholder text on the layer for every state (waiting / connecting / phone left the page / paused / lost), several phones at once, a layer turned portrait ↔ landscape keeps its shape (`phoneFit`), deleted phone layers let the phone go after 15 s (Ctrl+Z in time keeps it). New for every camera: **digital zoom + pan** (`L.dz`, also used by hand / face tracking through `effCrop`).
  Small extras: "no camera found" toast offers the phone; the start bitrate is raised in the answer (`boost`) so the picture is sharp from the first second instead of climbing for ~20 s; 1440p / 4K / 60 fps chips are disabled when the phone can't do them.
  Verified in app\bin\prism-cam.exe with fake phones (headless Edge + fake camera over https://192.168.1.7:8543): connect < 1 s at 1920×1080 H.264, two phones at once, resolution change from the phone and from the PC, pause / resume both ways, screen off / on, page reload, page hidden / shown, Prism Cam killed and reopened (phone back within 1 s), removed phone asking again (join button), QR dialog TH / EN.
