# Prism Cam — changelog (newest first)

Format: `YYYY-MM-DD — what changed — why`. Add a line after every fix/feature.

- 2026-11-18 — First public release v1.0.0 on GitHub (Pangpond543/prism-cam): `tools/release.sh` builds `Prism-Cam-<ver>-Setup.exe` (own NSIS script `tools/installer.nsi`, per-user, no admin) and `-Portable.zip`. In-app updater for packaged copies now downloads the matching release file (`update::apply_release`: installed → new Setup.exe run with `/S /RELAUNCH` on restart; portable → zip unpacked over the folder, files in use renamed to `*.old`, cleaned on next start). Source checkouts still rebuild with cargo. Basic hand poses taught by the author (built-in poses + “no pose” + heart / pray, no custom poses) ship in `app/renderer/data/default-hands.json` and fill the profile on first start; hand-profile menu → “use the default basic poses”. Translation audit: ~220 Thai strings of the Hand tab / teaching / F9 / PC control had no English → all added (`lang-en.js`); macro placeholder example translated. README rewritten (TH + EN, F9 tip). — user request.


- 2026-11-18 — Animation area = one object, like a video: moving / resizing / turning the box (handles, group box, wheel, numbers, "fill screen") carries everything inside — positions, sizes, turn, radius / border and their keyframes (`syncAreas` / `carryKids`, box remembered in non-saved `_f`). Alt while dragging an area handle = box only; "fit box to contents" (area panel + right-click). In animation mode the contents scale with the area's animated width / height too (`areaKx/areaKy`, `hooks.rest` = the area's box before the running edit, so the drag previews live). Editing inside an area: a click outside its box steps back out (`leaveAreaAt`) — marquee / clicks no longer get stuck on the inside layers. — user request.
- 2026-11-18 — Fix: resizing several selected layers warped in animation mode — the group remembered un-animated sizes/turns before `hooks.begin` stood the layers where the animation shows them (`groupItems` now calls begin first). Areas in the group now scale their contents. — user report.
- 2026-11-18 — Fix: switching output portrait ↔ landscape made everything smaller each time (sizes × min(kx, ky)). Now `resizeOut`: positions follow the canvas, sizes × √(kx·ky) (round trip is lossless), layers that filled the canvas fill the new one (media re-cropped, not squashed), keyframes and area contents follow; toast with Undo. — user report.

- 2026-11-16 — Several poses → several clips: overview of every hand-driven clip (source, pose, grab) in the Triggers tab, ⚠ when two clips use the same pose + input, "new clip for another pose" (picks an unused pose, grab on). Value tools for selected keys per property: make equal (first / average), even steps, flip — in the keys panel and the timeline / graph right-click menu. Onion skin toggle in the toolbar: selected layers as ghosts at the 2 previous (blue) / next (pink) keyframes with time labels (`drawOnion`, `studio.sourceOf`). — ideas the user picked.

- 2026-11-16 — Hand-driven time: "only with hand pose" (`drive.gest`, single or two-hand poses, meter says "waiting for pose"), "grab & drag" (`drive.grab`: time moves on from where it was, no jump), quick presets fist / pinch to scrub. Graph view: shows every curve of the selected layers / keys / rows, colour = layer, line style = property, one-row legend (click = hide, Alt+click = only that one), same property shares one scale, curves with selected keys bold; dragging a handle gives every selected key the same curve. Ctrl+Z works right after clicking a number box (a box keeps its own typing-undo only while something was typed). Property rows no longer open by themselves while several layers are selected (`autoExpand`). — user request.

- 2026-11-16 — Fix: pressing K / the add-key button / the "+" menu on a layer with no keyframes stored "no value" (X Y shown as NaN) and the picture jumped to the top-left corner. Cause: the new row was created before the layer's value was read (`dispV` found an empty row). `dispV` now falls back to the layer's own value, `setKey` refuses empty values, `fixClip` drops broken keys from old saves. — user report with screenshots.

- 2026-11-16 — Fix: pictures inside an area could not be multi-selected / dragged when picked from the timeline (selection only kept layers of the open list, the stage hit the whole area) → selecting a layer opens its area (`select` / `selectMany` switch `scope`). Fix: collage inside an area fell back to the centre outside Edit mode — the user's clip is hand-driven (`drive: handx`) and a driven clip only applied after a hand was seen → `lost: hold/reset` keep the clip on (start pose before any hand). Single 0 s keys of normal clips are baked into the layer on leaving Edit mode / on start (`bakeStatic`). "Key jumps to top-left" not reproduced with the user's save. — user report.

- 2026-11-16 — Library tab (`project.lib`: every imported picture / video, thumbnails, search, filter, drag onto stage / area, same file re-import reuses storage), area templates (`project.tpl`, save area or selection, insert from library with its keyframes + own clip), area timeline (clips with `area` id: play by themselves while the area is shown, restart when it appears), slideshow areas (`slides`: auto / on command, fade / slide / zoom / flip, page dots, swipe gestures), gesture commands `layer-show:` `layer-hide:` `slide-next:` `slide-prev:` + quick buttons in the area panel. Panel tabs: only the open one shows its name. — big ideas the user picked.

- 2026-11-16 — Drag layers like files: grab one or many rows (layer list or animation timeline), they gather under the mouse with a count badge and a label saying what the drop does (put into area / move here / move out / cancel), then fly into place; drop on an area row, on an area on the stage, or reorder between rows. On the stage: drag over an area + hold Ctrl = put inside. Files dropped on an area land inside it, where dropped. Layer clipboard Ctrl+C / X / V (with area contents + keyframes), Ctrl+Shift+V = paste into the selected area, right-click empty stage menu; images / videos copied in File Explorer paste with Ctrl+V. — user asked; also asked for more than the literal request.
- 2026-11-16 — Many keyframes at once (value rows per property with `+10` / `*2` syntax and drag, time tools: to playhead, same time, space evenly), property rows + presets (with stagger) apply to every selected layer; show all / hide all / solo (Alt+eye) / Ctrl+H, "N hidden — show all" bar; align & distribute. — user: "adjust together" meant keyframes; hide-all had no show-all.
- 2026-11-16 — Animation areas (`type: 'area'`, own `kids` list, double-click to edit inside, Ctrl+G), multi-layer property editing, layer hover preview, per-zone undo (stage/layers · animation · hand), imported videos saved to `<data>/media` and streamed back via `http://pmedia.localhost/` — user request.

- 2026-11-16 — Fix: pictures vanished from the save (layers left as empty "loading" boxes). Saving no longer deletes an image while Ctrl+Z/Ctrl+Y history can still bring its layer back — pictures lost this way before cannot be recovered, re-add them.
